# Aventuras do Rick — RBR

Jogo infantil interativo (Colorir + Jogar) com o Rick oficial da RBR. Funciona no computador e no celular.

## Como publicar no GitHub Pages
1. Crie um repositório novo no GitHub (ex.: `aventuras-do-rick`).
2. Envie **todo o conteúdo desta pasta** (index.html, assets/, videos/) para a raiz do repositório (Add file > Upload files).
3. Vá em **Settings > Pages**, em *Source* escolha **Deploy from a branch**, branch **main**, pasta **/ (root)** e salve.
4. Em 1–2 minutos o jogo abre em: `https://SEU-USUARIO.github.io/aventuras-do-rick/`

Para testar no seu computador, rode `python3 -m http.server` nesta pasta e abra `http://localhost:8000`.
